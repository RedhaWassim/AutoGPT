# Edenai Media
<!-- MANUAL: file_description -->
Speech, audio and image blocks backed by Eden AI expert models through the V3 Universal AI endpoint: text to speech, speech to text and image generation. Each block picks its provider with an Eden AI model string `feature/subfeature/provider[/model]`. Requires an Eden AI API key (`edenai` credential) from https://app.edenai.run.
<!-- END MANUAL -->

## Eden AI Generate Image

### What it is
Generates an image from a text prompt with an Eden AI expert model.

### How it works
<!-- MANUAL: how_it_works -->
The block sends the prompt to the `image/generation/<provider>[/<model>]` model (OpenAI, Google Imagen, ByteDance, Leonardo, Stability AI, ...) with an optional resolution. Eden AI returns a temporary download URL; the block stores the image in the user's workspace so the output stays available after the URL expires. Optional `fallbacks` lists providers to try if the primary one fails.
<!-- END MANUAL -->

### Inputs

| Input | Description | Type | Required |
|-------|-------------|------|----------|
| prompt | Text description of the image to generate | str | Yes |
| model | Eden AI image generation model, `image/generation/<provider>[/<model>]` (bytedance, google, leonardo, minimax, openai, stabilityai, ...). | str | No |
| resolution | Image size such as '1024x1024'. The provider default is used when empty. | str | No |
| fallbacks | Up to 3 fallback providers tried in order if the primary one fails. | List[str] | No |

### Outputs

| Output | Description | Type |
|--------|-------------|------|
| error | Error message if the operation failed | str |
| image | The generated image | str (file) |

### Possible use case
<!-- MANUAL: use_case -->
**Marketing visuals**: Generate an illustration for each blog post an agent drafts.

**Provider comparison**: Run the same prompt through several providers by changing the model string.
<!-- END MANUAL -->

## Eden AI Speech To Text

### What it is
Transcribes speech from an audio or video file with an Eden AI expert model.

### How it works
<!-- MANUAL: how_it_works -->
Speech to text is an async Eden AI feature: the block creates a job on `POST /v3/universal-ai/async` with the `audio/speech_to_text_async/<provider>` model and polls it until it completes (up to 15 minutes). Public URLs are passed as-is; workspace files and data URIs are uploaded to Eden AI file storage first. It returns the transcription and, when the provider supports diarization, the speaker segments.
<!-- END MANUAL -->

### Inputs

| Input | Description | Type | Required |
|-------|-------------|------|----------|
| audio | Audio or video file to transcribe: a URL, a workspace file or a data URI. | str (file) | Yes |
| model | Eden AI speech-to-text model, `audio/speech_to_text_async/<provider>[/<model>]` (amazon, assembly, deepgram, gladia, google, ...). | str | No |
| language | Language code of the speech, e.g. 'en'. Detected by most providers when empty. | str | No |
| fallbacks | Up to 3 fallback providers tried in order if the primary one fails. | List[str] | No |

### Outputs

| Output | Description | Type |
|--------|-------------|------|
| error | Error message if the operation failed | str |
| text | The transcription | str |
| speakers | Speaker segments, when the provider returns diarization | List[Dict[str, Any]] |

### Possible use case
<!-- MANUAL: use_case -->
**Meeting notes**: Transcribe a meeting recording, then summarise it with an LLM block.

**Voice notes to tasks**: Turn recorded voice notes into text an agent can parse into to-dos.
<!-- END MANUAL -->

## Eden AI Text To Speech

### What it is
Converts text to speech with an Eden AI expert model.

### How it works
<!-- MANUAL: how_it_works -->
The block sends the text to the `audio/tts/<provider>[/<model>]` model (OpenAI, ElevenLabs, Google, Amazon, Microsoft, Deepgram, ...) with an optional voice and audio format. Eden AI returns a temporary download URL; the block stores the audio in the user's workspace so the output stays available after the URL expires.
<!-- END MANUAL -->

### Inputs

| Input | Description | Type | Required |
|-------|-------------|------|----------|
| text | Text to convert to speech | str | Yes |
| model | Eden AI text-to-speech model, `audio/tts/<provider>[/<model>]` (amazon, deepgram, elevenlabs, google, microsoft, openai, ...). | str | No |
| voice | Provider voice name or ID. The provider default is used when empty. | str | No |
| audio_format | Audio format, e.g. 'mp3' or 'wav'. The provider default is used when empty. | str | No |

### Outputs

| Output | Description | Type |
|--------|-------------|------|
| error | Error message if the operation failed | str |
| audio | The generated speech | str (file) |

### Possible use case
<!-- MANUAL: use_case -->
**Audio summaries**: Turn a daily report generated by an agent into an audio briefing.

**Accessible content**: Produce spoken versions of articles or onboarding messages.
<!-- END MANUAL -->
